MM-ABC: Towards Generalist Mobile Manipulation via Seeing, Coordinating and Imagining

Qiwei Liang, Guangyu Chen, Shaolong Zhu et al.

问题：移动操作中，机器人在连续自运动下需要稳定的空间感知，并协调机械臂与移动底座这两类异构动作流。现有方法要么依赖显式3D表示或预测世界模型，要么将移动与操作解耦为独立动作流，难以实现高效的跨流协作。
方法：提出统一基础模型 MM-ABC，围绕“看见、协调、想象”构建机械臂-底座协作。它融合稀疏多层级 VLM 特征进行空间感知；引入仅在训练时使用的未来分支，以世界想象和几何意图作为额外监督；并用 MM-APT 通过掩码联合注意力和干净动作 x-prediction 协调操作与移动两个独立动作流。
结论：在 EBench、RoboCasa365、ManiSkill-HAB、LIBERO、LIBERO-Plus 及真实世界移动操作任务上取得领先效果：EBench 44.71%、RoboCasa365 61.2%、LIBERO 99.1%、LIBERO-Plus 82.8%，真实五任务平均成功率 83%。消融显示，用速度预测替代干净动作预测会使 RoboCasa365 成功率从 32.8% 降至 29.2%，移除未来监督或多层级条件则下降更大。
创新点：将未来世界想象与几何意图作为训练期监督，并通过掩码联合注意力与干净动作预测实现机械臂和底座双动作流的高效协调。
意义：为通用移动操作基础模型提供了可扩展的感知、协调与想象框架，推动机器人从固定基座操作走向全身移动操作。

DynaTokens: Teaching Dynamics to Camera-Controlled Video Models at Test Time

Ziqi Ma, Hongqiao Chen, Georgia Gkioxari

问题：相机控制的视频模型在静态场景中表现良好，但在动态场景中难以同时处理相机运动和物体自身运动，导致物体静止、运动错误或生成质量下降。
方法：提出 DynaTokens，一组轻量可学习的场景特定 token，通过 cross-attention 注入现有相机控制世界模型，在冻结基础模型的情况下，用少量示例轨迹训练，从而学会场景动态，并支持在新相机路径下生成动态。
结论：在 VBench2 和 WorldScore 上，DynaTokens 在动态与相机控制的权衡上优于 LoRA、block finetuning 和可训练层基线，并说明可训练接口需匹配学习目标结构。
创新点：利用相机运动全局性、物体动态局部性的不对称性，以少量场景特定 token 在测试时教会冻结的相机控制视频模型生成动态。
意义：为视频世界模型和相机可控视频生成提供了一种高效、轻量的测试时适配思路，有助于提升动态场景下的可控生成能力。

Control-Geometry Straightening for Sampling-Based Latent Planning

Ziang Fu, Ning Ning

问题：在基于潜在世界模型的规划中，仅靠准确的转移预测并不能保证规划目标容易优化，导致采样规划在有限预算下效率不高。
方法：提出 Control-Geometry Straightening (CGS)，一种单一辅助损失，利用像素-动作对的局部转移，将动作之间的成对余弦相似度与对应潜在差分之间的相似度匹配，从而直接拉直控制几何，可适配端到端学习或预训练表示的多种世界模型架构。
结论：在四个控制环境和多种规划器上，CGS 能用更少的采样候选和精修步数提升规划性能，相比 LeWM 和 LeWM+TS 成功率分别最高提升 20 和 12.6 个百分点（每次更新使用 128 个候选）。
创新点：首次通过直接拉直控制几何的辅助损失来学习对采样规划友好的潜在表示，并与 MPPI、CEM、梯度下降等规划器的理论性质建立联系。
意义：为潜在世界模型和基于采样的规划提供新的表示学习视角，有助于提升具身智能与控制任务在有限规划预算下的决策效率。

WorldPlay2: Extending Real-Time Interactive World Models in Control and Horizon

Haiyu Zhang, Wenqiang Sun, Tengfei Wang et al.

问题：交互式世界模型需要实时响应多种控制并保持长时程一致性，但异构控制建模困难，且长上下文与不稳定蒸馏难以同时实现长时程一致性和实时响应。
方法：提出WorldPlay2，将因子化混合控制接口与压缩记忆、稳定蒸馏协同设计：控制接口结合帧对齐动作控制与结构化语义控制，显式解耦场景外观、角色身份和动态语义事件；将历史上下文压缩为记忆token，由自回归学生和双向教师共享，实现片段级记忆条件评分；并提出Stable Forcing，通过少步初始化与全rollout回放稳定蒸馏。
结论：大量实验表明该模型具有较强泛化性，并优于现有方法；摘要未给出具体量化指标。
创新点：通过因子化混合控制接口与压缩记忆、Stable Forcing的协同设计，兼顾异构控制、长时程一致性与实时蒸馏效率。
意义：推动实时交互式世界模型在可控性、长时程一致性和训练效率方面的发展，对世界模型、Agent与具身智能研究有参考价值。

Humanoid Loco-Manipulation With Discrete VLA Model

Wenxin Shao, Siqi Chai, Kun Li et al.

问题：现有离散动作 token 的 VLA 模型主要面向机械臂操作，而人形机器人的全身动作空间（腿、躯干、手臂、手）维度更高且异构，带来 token 化、训练和实时推理方面的挑战。
方法：论文提出 Holo-M，一个面向人形 loco-manipulation 的离散 VLA 模型，通过将动作 token 加入语言模型词表来利用语言模型能力。其统一动作 tokenizer 将人形动作空间分解为四个身体部位专用 tokenizer：末端执行器、身体、手和运动学，从而支持人形遥操作、自我中心人类视频和仿真等不同具身与数据源的训练。为满足实时控制，模型采用分组离散扩散解码而非对动作 token 做自回归解码。
结论：在 SIMPLE 人形 loco-manipulation 基准上，Holo-M 在通用和专用评测中均取得最高成功率，并显著领先第二名。作者表示将开源全部代码和模型权重。
创新点：首次提出面向人形 loco-manipulation 的离散 VLA 模型，并通过四类身体部位动作 token 与分组离散扩散解码解决异构高维全身动作控制问题。
意义：为高维人形全身控制与跨具身、多数据源 VLA 训练提供了新范式，推动具身智能中语言模型与全身动作生成的结合。

FlowTool: Controlling Tool Parameter in Image Retouching via Flow Matching

Thanh-Long V. Le, Steven Walton, Seunghyun Yoon et al.

问题：现有基于工具的图像编辑通常依赖自回归多模态大模型依次生成推理、工具选择和参数值，效率低且参数生成可能不够直接。
方法：FlowTool 将工具参数控制建模为条件流匹配问题，结合视觉语言模型主干和 Diffusion Transformer 参数生成器，用条件修正流将高斯噪声转换为编辑计划，并采用两阶段监督流匹配课程与基于奖励的后训练。
结论：在 MMArt-Bench、FlowTool-Eval、ArtEdit-Bench 和 MIT-Adobe5K 上，FlowTool 的参考评估显著优于专用 MLLM 编辑代理和专有 MLLM，无参考评估中也具竞争力，同时推理延迟至少降低 50 倍、内存需求减少近 2 倍。
创新点：提出将基于工具的图像编辑参数生成从自回归推理转变为条件流匹配生成，无需自回归推理即可直接建模高质量工具参数分布。
意义：为多模态图像编辑与工具型 Agent 提供了一种更高效、非自回归的参数生成范式，对多模态大模型和生成式控制方向有启发意义。

PhoneCLI: From App Interfaces to Callable Commands for Mobile Agents

Yangqin Jiang, Lingrui Xu, Chao Huang

问题：移动 GUI Agent 依赖逐步截图、调用 VLM 并发出动作的感知-行动循环，速度慢、成本高且脆弱，而大量操作其实是静态、有序、重复的导航。
方法：PhoneCLI 在不依赖 App 内部 API、运行时插桩或模型训练的情况下，离线从外部探索 App，将屏幕、交互元素和导航边蒸馏为语义地图，并为每个屏幕生成一个确定性回放命令；在线时 Agent 选择命令、执行前验证，并以亚秒级、零 VLM 成本执行，失败时回退到嵌入式 VLM 解释器。
结论：在 AndroidLab 上，PhoneCLI 提升了任务成功率，同时减少执行步数和 token 消耗；迁移到 AndroidWorld 官方 M3A Agent 后也能带来一致的效率提升。
创新点：将 App 的 GUI 导航编译为可调用、可复用、可确定性执行的命令，而不是只优化单次任务轨迹，并用 VLM 回退机制保证编译失败时不降低原有能力。
意义：为移动 Agent 提供了一种无需训练和系统改造、可显著降低 VLM 调用成本并提升执行效率的通用加速范式。

Yuhao Zhang, Keisuke Okumura, Ajay Shankar et al.

Verifiable Visual Rewards Transfer from Synthetic Scenes to Natural Prompts

方法：提出无需训练的“Look Before You Judge”框架，将可解释深度伪造检测建模为序列化证据获取过程：先通过对比原图与高斯模糊图在MLLM解码器到视觉注意力上的差异，定位图像特定的候选证据区域；再逐个检查局部区域，并将其与全局图像上下文结合后给出最终判定。
结论：在TriDF和MMTD-Set上，对五种开源MLLM进行实验，检测准确率最高提升12.8%，CHAIR最高降低33.4%，幻觉率最高降低21.3%，并优于代表性的免训练解码与注意力方法。
创新点：无需人工伪造掩码、外部取证模型或参数更新，通过原图与模糊图的注意力对比挖掘局部证据区域，实现免训练且视觉可定位的深度伪造解释。
意义：为MLLM在深度伪造检测中提供更可靠、可解释且可直接部署的视觉 grounding 思路，有助于提升AI取证系统的可信度。

Sprout: Building Dynamic Memory While Reasoning for Agentic Video Understanding

Wei Chen, Xuanyu Zheng, Yancheng Long et al.

问题：长视频理解中，现有离线构建再推理的视频记忆方法成本高且无法在回答多个问题时动态更新，导致重复构建和已获得的信息丢失。
方法：提出 Sprout，一种在推理过程中动态构建记忆的智能体框架：以低帧率逐段观看视频，将每段记为时间树中的粗粒度节点，并在需要时以高帧率回看关键区间来细化记忆；已转为文本的视频段从上下文中移除，但可通过视频工具重新访问。
结论：在三个模型和多个基准上，Sprout 达到与代表性离线记忆方法相当或更好的准确率，同时无需前期构建阶段，并降低每个问题的上下文成本。
创新点：将视频记忆从静态离线构建转变为随问题在线生长的时间树，用文本记忆替换累积视频输入，实现动态、可复用的智能体视频理解。
意义：为多模态大模型处理长视频提供了一种更高效、可扩展的在线记忆机制，有助于推动智能体式视频理解的发展。
