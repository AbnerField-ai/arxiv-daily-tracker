YANAMI: A Large-Scale Multimodal Dataset and Benchmark for Multiturn Stateful Interaction

Shengyu Wang, Tengyue Nong, Junming Liu et al.

问题：现有统一多模态模型（UMMs）的数据集与基准以单轮任务为主，即使是多轮数据也存在大量可独立求解的轮次，缺乏对需要跨轮追踪、维护和更新对话状态的多模态「有状态交互」的监督与评测。
方法：论文提出 YANAMI，包含两部分：YANAMI-400K 是 40 万条多轮多模态对话，含 200 万+ 张图像与 260 万+ 轮对话，覆盖多图融合、图像编辑、世界建模、视觉推理四大场景，要求模型持续追踪与修订演进中的多模态对话状态；YANAMI-Bench 含 400 条多轮对话，联合评测「对话状态理解」与「视觉实现」两方面能力。
结论：在 YANAMI-400K 上微调 BAGEL 后，图像编辑、图像生成与多模态有状态交互分别提升 10.3%、2.0% 和 13.23%，同时保持通用视觉理解能力；YANAMI-Bench 评测显示现有 UMMs 在维护、更新并视觉化实现演进对话状态方面仍普遍困难。
创新点：首个面向多模态有状态交互的大规模多轮对话数据集与双维度（状态理解 + 视觉实现）评测基准，明确区分「理解状态」与「忠实呈现状态」之间的差距。
意义：为统一多模态模型从单轮生成迈向跨轮状态一致的多轮交互提供了规模化训练数据与标准化评测，推动世界建模与多模态 Agent 方向的状态一致性研究。

Trajectory Evaluation via Rollout-Free World Model for End-to-end Autonomous Driving

Junzhe Wang, Jinqing Zhang, Qingjie Liu

问题：现有端到端自动驾驶的候选轨迹评估器依赖对未来状态进行显式递归预测（rollout），带来高推理成本与预测误差累积的问题。
方法：提出 RFWorld，一种无需 rollout 的世界模型：构建共享场景记忆，并通过带语义监督的轻量训练时时间读出，将其塑造成可被未来读取的表示；推理时候选轨迹直接通过稀疏空间读出查询共享记忆完成打分。
结论：在 NAVSIM 和 Bench2Drive 上取得 state-of-the-art 性能，学到更贴合规划的世界表示，并将计算量减少约“规划时域×候选轨迹数”倍，同时避免递归预测误差。
创新点：用共享场景记忆与稀疏查询替代逐候选的未来场景重建，实现无 rollout 的未来感知轨迹评估。
意义：为端到端自动驾驶中世界模型的高效使用提供了新范式，兼顾性能与推理效率。

GUILD: Guided Iterative Data Collection for Imitation Learning

Shivin Dass, Kevin Nguyen, Rohan Yelandur et al.

问题：机器人模仿学习依赖昂贵的真实遥操作数据采集，而传统采集缺乏引导，常产生对策略性能贡献很小的数据；现有筛选方法只能在采集后过滤，无法避免采集无信息数据。
方法：提出 GUILD，一种引导式数据采集框架，迭代交替进行任务提议与数据采集、数据评估。它利用视觉语言模型的语义先验提出相关环境、物体配置和目标，并用预测性数据归因估计已采集轨迹对目标部署场景策略性能的影响，再将此信号反馈以指导后续采集。
结论：在仿真和真实机器人实验中，GUILD 相比被动采集策略、多个基线以及有经验的机器人专家，显著提升了样本效率和部署性能。
创新点：将视觉语言模型语义先验与预测性数据归因结合，形成面向下游策略性能的闭环主动数据采集框架。
意义：为机器人模仿学习和具身智能中的数据高效采集提供了可主动优化策略表现的新范式。

JHiMA-WebRL: A Joint Hierarchical Multi-Agent Reinforcement Learning Framework for Long-Horizon Web Tasks

Shanka Subhra Mondal, Jiayun Wang

问题：多模态网页智能体在长时程、多步骤网页任务中难以同时完成高层规划、状态导航、进度跟踪和视觉动作执行；已有模块化多智能体方案中的规划器通常不与执行器联合更新。
方法：提出 JHiMA-WebRL，将任务分解器（decomposer）与子任务条件执行器（actor）组成分层多智能体框架：先用强教师模型从多模态 GUI 轨迹构建结构化子任务监督并微调两者，再将 GRPO 扩展为分层 rollout 分组和角色特定优势，在 WebArena 中联合优化分解器与执行器。
结论：在 WebArena-Lite-v2 上，由 7B actor 和 7B decomposer 组成的 JHiMA-WebRL-14B 平均成功率达 37.2%，高于同训练任务和评测协议下经 RL 微调的 ScaleCUA-32B 的 24%；消融表明 RL 阶段联合更新 decomposer 优于仅更新 actor。
创新点：核心创新是显式分离规划与执行角色，并通过分层多智能体强化学习将任务分解器与执行器联合训练，而非仅使用固定规划器。
意义：结果表明联合学习角色分解的小模型组合可成为长时程网页任务中替代单纯扩大单体智能体规模的有竞争力方案。

Should the Action Expert Train the VLM? Action-Token Supervision and Gradient Routing in Mixture-of-Transformer VLAs

Asher James Hancock, Boyi Li, Yuxiao Chen et al.

问题：VLA模型中动作专家是否应通过梯度回传训练VLM，以及动作token监督与梯度隔离各自的作用尚不清晰，需要厘清默认训练配方的合理性。
方法：在自动驾驶和机器人操作任务中，独立变化动作token监督与专家损失是否更新VLM（耦合 vs. 隔离），比较开环/闭环驾驶和操作性能。
结论：有动作token监督时，隔离与耦合在开环驾驶中相当；无监督时耦合降低轨迹误差约25%。联合训练时，耦合在有/无动作token监督下分别提升闭环路线进度约17%和40%，并改善机器人操作性能。
创新点：系统解耦并实证评估动作token监督与梯度路由对VLA训练的影响，挑战“梯度隔离”作为默认训练配方的做法。
意义：为VLA/VLM与动作专家的联合训练配方提供实证指导，对多模态机器人和具身智能模型设计有直接意义。

Asynchronous Robot Policies

Sombit Dey, Luc Van Gool, Danda Pani Paudel

问题：现有VLA架构在主控制回路中顺序执行高层语义推理与动作执行，模型规模增大带来计算延迟，导致语义能力与机器人实时敏捷性之间存在根本矛盾。
方法：提出异步机器人策略ARP，将语义推理与底层动作生成解耦为独立频率的异步过程：高容量VLM低频异步更新语义记忆，轻量Vision-Action Expert基于该记忆高频生成动作；并针对语义记忆过期、执行延迟和时间错配观测训练专家模型。
结论：在Franka准静态任务中成功率提高18%、执行时间减少20%，动态仿真环境中达到基线3-5倍性能；VLM以低至其标称频率1/10运行仍无显著性能损失。
创新点：将机器人策略建模为独立频率的异步过程，并通过面向语义过期与执行延迟的训练实现快速感知-动作闭环而不牺牲基础模型语义能力。
意义：为大规模视觉语言基础模型在真实机器人中的实时反应式部署提供了架构思路，有望缓解模型规模与物理实时性之间的矛盾。

PolicyIK: High-Precision Inverse Kinematics for Robot Arms with Reinforcement Learning

Yuhan Liu, Xinqi Liu, Zixuan Dong et al.

问题：机器人手臂的逆运动学（IK）在高精度场景下仍很困难：冗余和奇异位形使逆映射复杂，执行依赖手工调参控制器，真实机器人训练数据采集成本高。
方法：提出 PolicyIK，一种目标条件强化学习策略，根据位姿反馈更新关节位置参考，并观测累计参考与实测关节的相对关系以保留位置控制器所需偏移；采用双尺度位姿误差、随误差变化的动作增益以及进度/驻留奖励来兼顾大范围运动与毫米级残差。
结论：仿真中单次尝试在93.5%的留出任务上最终1秒平均误差低于1 mm和0.2°，部署协议将成功率提升至98.9%；真实机械臂上优于四种经典IK控制器，并在仿真拾放中以95.7%成功率执行π0.5 VLA策略的末端指令。
创新点：将强化学习策略训练为高精度IK控制器，并通过参考偏移观测、双尺度误差增益和进度/驻留奖励实现毫米级到达与保持。
意义：表明RL可提供高精度机器人逆运动学，有助于提升VLA策略的精确执行和跨本体迁移能力。

Möbius: A Unified Motion-Language Model Bridging Understanding and Generation

Jiazhi Shu, Chengfeng Zhao, Jinyi Wang et al.

问题：现有运动统一多模态模型（UMM）只是部分统一：运动理解由语言模型完成，而生成则交给独立的扩散模块在学到的运动隐空间上进行，导致理解与生成割裂，且依赖离散分词或预训练运动VAE。
方法：提出 Möbius，将整个扩散过程直接搬进与运动理解共享的多模态表示空间：干净运动、加噪运动和文本共同参与共享注意力，理解流与生成流由角色专属参数分别处理。模型直接在连续的帧级原始运动上操作，无需离散分词也无需预训练运动VAE，从而用单一模型支持运动描述、文本生成运动、时序补全和指令引导编辑。
结论：在 HumanML3D 上，Möbius 在统一运动模型中达到 SOTA；扩展到 1.7B 参数和 1700 小时运动数据后仍表现良好，验证了框架的有效性与可扩展性。
创新点：把扩散生成完全纳入理解所用的同一多模态表示空间，并直接在连续原始运动上建模，摆脱了运动分词器与预训练运动VAE的依赖，实现理解-生成-编辑的真正一体化。
意义：为统一多模态世界模型提供了一条“表示空间统一而非模块拼接”的简洁路径，对多模态大模型与具身智能中的运动/动作建模具有参考价值。

Factorized MLLM Embeddings for Composed Image Retrieval

WonJun Moon, Seongchan Kim, Dahun Kim et al.

问题：组合图像检索（CIR）需要根据参考图像和修改文本检索目标图像；现有基于多模态大模型（MLLM）的方法仅用对比监督将组合查询直接映射为检索嵌入，未显式解析预期的视觉修改，导致 MLLM 的组合理解能力未被充分利用。
方法：论文提出 FactEmbed，将组合查询理解与判别性嵌入构建解耦：用一组分解潜在变量通过中间“目标想象”目标模拟预期视觉修改，使潜在变量先对齐目标语义；再用因子级对比损失并将分解表示蒸馏到 MLLM 更深注意力层。推理时保留 [EOS] 全局嵌入，并用同一前向得到的均值池化因子潜在变量对短候选列表重排序。
结论：在多个 CIR 基准上优于已有方法，且重排序几乎不增加额外成本，实现了高效推理。
创新点：核心创新是用因子化潜在变量和中间目标想象目标显式建模组合查询中的视觉修改，并结合因子级对比学习与表示蒸馏提升检索嵌入。
意义：该工作提升了 MLLM 在组合多模态检索中的细粒度理解与表示能力，对多模态检索、组合理解及大模型嵌入学习具有参考价值。

What Does the Model See? Representation Validity in Multimodal LLM-Based Video Analysis

Christian Pipal, Eva-Maria Vogel, Morgan Wack

问题：在使用多模态大模型分析视频时，研究者需要决定向模型输入视频的哪些部分（文本、音频、视频或组合），但不同输入表征如何影响测量结果及后续分析尚不明确。
方法：论文提出“表征有效性”（representation validity）概念，比较文本、音频、视频及组合输入在六个开源多模态大模型和三个带人工标注的视频数据集上的表现，并评估分类性能与下游回归系数、样本流行率估计是否接近人工编码基准。
结论：没有一种输入表征始终最优：原生视频的宏F1在不同模型间为0.70-0.77，提取文本为0.52-0.80；组合输入很少提升性能；更高分类准确率也不 reliably 带来更接近人工编码的下游估计。最高F1表征仅在42次比较中的17次最好地复现人工编码回归系数，且即使使用各模型最高F1的可部署表征，仍有45%的样本流行率估计与人工基准相差超过10个百分点。
创新点：系统提出并验证了多模态大模型视频分析中的“输入表征有效性”问题，强调分类准确率不足以保证下游统计估计有效。

结论：在 Qwen3.6-35B-A3B 上，Cookie-Bench Mini Games 得分从 68.8 提升到 75.3，WebGen-Bench 准确率从 48.8 提升到 56.9，在各项指标的平均排名上超过 Claude Opus 4.7。
创新点：首次把高保真、运行时可验证的交互反馈（GUI 评估 + 视觉锚定 + 执行轨迹信用分配）系统性地引入交互式 HTML 生成的强化学习中。
意义：表明提升反馈保真度是推进交互式 HTML/前端代码生成的关键，为代码 LLM 的 RL 训练与可交互产物生成提供了新范式。

LoopQ: Fair, Closed-Loop Evaluation of Quantized Vision-Language-Action Models

Syed Umer Bukhari, Magnus Almgren, Ahmed Ali-Eldin

问题：现有视觉-语言-动作（VLA）模型的后训练量化（PTQ）工作难以公平比较，因为不同方法常在不同检查点、层或推理引擎上评估，导致难以判断VLA专用量化方法是否真正优于通用或更简单的PTQ方法。
方法：作者提出LoopQ闭环基准，在同一检查点、相同层和相同引擎上仅改变量化方法与kernel，对RTN、AWQ、GPTQ、ActQuant和QuantVLA进行比较；在4个VLA模型、LIBERO与LIBERO-plus超过18万条episode上评估，并尝试复现4个公开VLA量化发布，同时在NVIDIA H100、L4和Jetson AGX Thor上测试性能。
结论：结果显示量化能稳定节省内存（真实低比特模型约2-3倍），但VLA专用PTQ方法在4比特下并未优于RTN、AWQ、GPTQ等通用基线，甚至RTN可匹配校准方法、AWQ可匹配QVLA自报成功率；标准LIBERO会掩盖损失，在配对LIBERO-plus扰动下无显著LIBERO损失的配置仍会下降1.5-4.3个点；速度收益更弱，H100 batch 1下没有量化pi0.5或OpenVLA-OFT配置快于16比特模型，仅L4的int8 kernel有4-14%增益，Thor所有4比特配置都更慢，且仅引擎变化即可造成2.1倍延迟差异。
创新点：提出了受控、闭环且可复现的VLA量化公平评测框架，统一检查点、层与引擎，并结合多硬件基准和性能剖析揭示VLA专用量化方法的真实收益与局限。
意义：该工作提醒AI社区在VLA量化研究中应采用公平、闭环和多扰动的评测协议，避免被单一基准或非受控比较误导，对多模态具身智能模型的高效部署具有重要参考价值。

方法：提出 VIGOR，一种无需训练、即插即用的推理策略：每步同时用原图和视觉消融条件计算候选 token 置信度，比较视觉证据带来的增益，并优先解码更依赖图像支持的位置。

意义：为多模态扩散语言模型提供了一种无需额外训练的幻觉缓解思路，对可靠多模态生成有实际意义。

PATTS: Parallel-Aware Test-Time Scaling for Thought-Image Generation in Multimodal Discrete Diffusion LLMs

Yasong Dai, Zeeshan Hayder, David Ahmedt-Aristizabal et al.

问题：在多模态离散扩散语言模型中，推理 token 与图像 token 在同一条生成轨迹中联合解码，现有的 test-time scaling 方法只对最终图像或图像中心的中间状态排序，忽略了并行思维-图像轨迹的结构信息，导致验证器选择与 oracle 选择之间仍有较大差距。
方法：提出 PATTS 并行感知的测试时扩展框架，在生成过程中对中间“思维-图像”状态进行搜索，而非仅对完成图像排序。它利用模型内部轨迹诊断得到随状态变化的可靠性权重，动态调节外部跨模态语义验证信号的影响强度，实现可靠性感知的轨迹验证与选择。

创新点：首次针对并行多模态离散扩散 LLM 提出在中间思维-图像状态层面、并以模型内部可靠性信号调制跨模态验证的测试时扩展方法。
意义：为多模态扩散大模型的推理时计算扩展提供了新方向，表明对联合推理-生成轨迹做可靠性感知验证比仅筛选最终图像更有效。

Do Agentic Policies Need to Look at Every Step? Geometric Abstraction for Reasoning and Action

Yihang Liu, Yiming Chen, Mingzhe Zheng

问题：多模态语言模型在机器人操作中每一步都重复解析原始视觉观测，代价高且是否有必要尚不清楚；论文要回答智能体策略是否需要对每一步都做视觉重解析。
方法：提出一种3D几何抽象接口：用带类型、带证据感知的符号引用表示物体部件，从标定RGB-D中定位并绑定度量信息，每次动作后返回带度量残差的紧凑文本检查点；语言模型直接读取这些文本/符号，仅在需要时才回退到直接视觉推理。
结论：在离线策略合成和连续在线执行中，基于接地的文本与符号进行推理提升了多步操作任务的完成率，同时大幅减少重复的多模态查询次数。
创新点：把常规空间推理从图像迁移到可复用的符号化几何状态上，实现跨决策复用任务结构、按需重绑定当前场景度量值，并按需调用视觉推理。
意义：为具身智能体和机器人策略提供了以显式几何状态为基底的推理范式，可降低多模态调用开销并提升长程操作的可控性与效率。
