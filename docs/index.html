WorldGuide: Goal-Directed Video World Model for Procedural Task Execution

Ankan Deria, Komal Kumar, Hisham Cholakkal et al.

问题：长时程程序性视频生成需要根据已生成的视觉状态动态决定下一步动作、执行并判断终止，而开环生成无法适应执行结果，现有闭环系统又依赖预训练执行器或间接验证，导致“决定动作”与“成功实现动作”之间存在鸿沟。
方法：将程序性视频生成建模为视觉世界空间中的闭环任务执行，提出 WorldGuide：仅给定初始图像和任务目标，由 Planner 预测原子动作或终止，Executor 直接生成对应视频片段，二者在相同的步骤级演示上联合训练，并用分层视觉记忆以有界 token 成本维持长时程状态。同时构建约 59K 步骤标注视频、覆盖 245 个任务和 27 个程序类别的 WorldGuide Bench 用于训练与评测。
结论：在 WorldGuide-Bench 上取得 33.33% 任务成功率，高于接收参考动作计划的 MiniMax-H3（29.90%）；在 VideoCraft-Bench 仅目标条件下达到 47.69%，显著优于 MiniMax-H3 的 32.73%。
创新点：首次将程序性视频生成形式化为视觉世界空间中的闭环任务执行，并联合训练规划器与执行器，通过分层视觉记忆和步骤级标注基准实现目标导向的长时程程序生成。
意义：为视频世界模型从被动生成走向目标导向、可自适应的任务执行提供了新范式，对具身智能和 Agent 的长时程规划与执行研究具有推动作用。

WorldCast: Distributed Multiplayer World Models

Ziyang Ye, Junchao Huang, Evelyn Zhang et al.

问题：多人世界模型需要为每个玩家生成独立控制的视角，同时保持玩家和共享环境表示一致；现有联合多视角生成方法的计算成本随玩家数量增加而增长。
方法：提出WorldCast，一种分布式多人世界模型：每个玩家运行本地客户端，包含视频生成器和状态模型；状态模型利用训练时的玩家位置与地图几何，从生成视频和控制输入中估计玩家位置。客户端交换玩家状态，并将其投影为相机对齐的玩家状态场，用于指导其他玩家的渲染位置与方式；共享场景状态使各客户端可复用他人生成的观测，以保持跨视角场景外观一致。
结论：在《反恐精英2》上的实验表明，WorldCast具有一致性、实时性和分布式可扩展性；相机对齐玩家状态场将玩家渲染速率比联合生成方法提升一个数量级以上，共享场景状态提升了整轮比赛的视觉一致性。每个客户端实时运行且仅交换玩家和场景状态，避免了集中式计算瓶颈，图像质量在长达一小时的 rollout 中保持稳定。
创新点：核心创新在于用分布式客户端架构替代联合多视角生成，并通过相机对齐玩家状态场和共享场景状态实现可扩展的多人实时世界模型。
意义：该工作推动了多人交互式世界模型与实时生成式模拟的发展，为可扩展、无中心瓶颈的多人生成环境提供了新思路。

方法：提出 LeWAM：一个双向 Transformer，在无解码器的 JEPA 潜空间上端到端联合训练前向动力学、后向动力学、逆动力学与策略预测四种模式。并在规划阶段提出“扩散引导”思路——不在原始动作空间采样，而是在策略头的噪声空间中做 MPC 规划。

创新点：把四种预测模式（前向/后向/逆动力学/策略）统一在无重建 JEPA 潜空间上端到端训练，并提出在策略头噪声空间做 MPC 规划以规避动力学模型误差。
意义：为世界模型与策略学习的表征共享、以及基于世界模型的规划提供了新范式，对具身智能与 Agent 决策方向有直接参考价值。

VersaCamVLA: Camera-Configurable VLA Policies for Robotic Manipulation

Boyao Han, Chen Shi, Jingjing Qian et al.

问题：现有VLA模型依赖训练时固定的相机配置，导致部署中相机数量或位姿变化时性能脆弱，难以适应真实机器人场景。
方法：提出VersaCamVLA框架，将相机集合表示与动作学习解耦：通过统一场景token接口把任意可变的有位姿RGB视图映射为固定大小的隐场景token；利用多信号目标视图预测和腕部增强位姿采样（WAPS）获得位姿多样性。部署时用轻量空间编码器将场景token作为额外视觉条件注入预训练基础VLA，无需显式3D传感或新视图渲染。

创新点：提出相机可配置的VLA策略，在不依赖显式3D感知或新视图渲染的情况下，使预训练VLA能适应任意可变相机集合与位姿。

OmniCapBench: A Deep-Structured Evaluation Framework for Fine-Grained Audio-Visual Captioning

问题：现有流式视频大模型（Streaming VLMs）的评测基准多聚焦低动态场景，而现实世界视频流包含大量快速事件；在有限上下文预算下，模型难以在时间历史、空间分辨率与时间粒度之间取得平衡，1–2 FPS 的稀疏采样会漏掉关键快动作。
方法：论文提出 FastBench，一个面向真实高动态视频流的评测基准：通过基于轨迹的流水线构建数据，包括从高帧率片段生成问答、过滤掉在 2 FPS 下即可回答的问题、用 SAM3 与 CoTracker3 轨迹验证答案，并经三轮人工审核；最终包含 306 个 QA 对，覆盖 8 个领域、6 种能力以及前向/即时/后向三种时间范围，并带有标注的证据区间。同时提出免训练的 ProactiveFrame 基线，通过文本 token 动态调节输入帧率，并用双层滑动窗口保留近期高帧率观测、将较早帧降采样为稀疏历史。
结论：实验显示现有模型能力明显不足：最强的 Gemini-3.5-Flash 仅得 50.7%；提高采样密度可让 Qwen3-VL-8B 从 2 FPS 的 32.9% 提升到 24 FPS 的 44.6%，但随历史被压缩增益趋于饱和；ProactiveFrame 比稀疏均匀采样高 5.4 和 1.5 个百分点，却仍远低于 oracle 引导的聚焦策略，说明模型难以仅凭视频流判断何时需要更细的时间感知。
创新点：首个针对高动态真实视频流理解构建、并以轨迹验证与人工标注证据区间保证质量的流式 VLM 评测基准，同时提出自适应帧率的免训练基线 ProactiveFrame。
意义：为流式视频大模型的高动态感知能力提供了可复现的测试平台，并揭示当前模型在时间采样与注意力决策上的根本性局限，为后续时序感知与上下文管理研究指明方向。

GeoReform: Reflective Formalization Evolution for Multimodal Geometry Problem Solving

Jialu Wang, Ruichen Zhang, Xiaoou Liu et al.

问题：多模态大模型在几何题中难以识别和利用图中的几何关系，现有将几何元素形式化为文本表示的方法容易引入冗余和歧义，反而干扰推理。
方法：提出 GeoReform，将几何形式化视为可优化的策略而非固定解析器输出。它执行完整推理流程，收集失败轨迹，诊断当前表示的缺陷，并变异策略以更好地选择、对齐、分组和呈现几何实体、关系、约束与目标。
结论：在 Geometry3K 上，GeoReform 将 Qwen3VL-2B 准确率从 42.0% 提升至 56.0%；实验表明有效形式化对多模态几何推理至关重要。
创新点：将形式化过程建模为可反思、可进化的策略优化，而非一次性抽取更多几何事实。
意义：为多模态大模型在几何/结构化视觉推理中的表示组织与自改进提供了新思路。

Mental-Models for Multi-Agent Systems

Hanan Gani, Lulu Shao, Manmohan Chandraker

问题：多智能体在部分可观测环境下决策时，需要推理其他智能体知道什么、意图是什么以及可能如何行动；现有智能体系统多依赖提示设计、记忆或端到端行为塑造，通常没有学到可跨任务复用的显式伙伴状态表示。
方法：论文提出“心智模型赋能智能体”框架，为智能体学习一个关于对手/伙伴的潜在心智模型，从观测历史中推断隐藏信念、意图和可能反应，并将其作为决策变量指导动作选择。方法学习摊销式递归心智理论表示，包含一阶和二阶心智状态结构，并与基于信念的条件奖励模型联合训练，以评估候选动作相对于推断伙伴状态的好坏，最后在该信念感知信号下学习策略。
结论：在纯语言和多模态基准上，同一框架都能一致提升交互质量和心智理论性能，优于基础智能体系统。
创新点：将显式、可复用的伙伴心智状态表示作为决策变量，并与信念条件奖励模型和策略学习联合建模，是一阶/二阶心智理论在多智能体基础模型智能体中的结构化落地。
意义：表明结构化的伙伴建模是通用多智能体系统和基础模型智能体的有效归纳偏置，有助于提升部分可观测协作与竞争场景中的决策鲁棒性。
