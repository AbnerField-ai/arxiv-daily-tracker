Auditing a Learned Simulator for Legged Robots: The Robotic World Model on ANYmal D

Joyjeet Singh

问题：学习型机器人模拟器通常只做单步训练和单步检查，但策略实际会自回归滚动上百步；论文要审计这类模拟器在长时程和机器人策略层面的可靠性，并以 Robotic World Model（RWM）在 ANYmal D 四足机器人上的模型为案例。
方法：作者无 GPU 地端到端复现并审计已发表的 RWM 动力学模型及其后续 RWM-U 的不确定性估计，精确匹配官方代码的输出、损失和梯度；测量 101 个训练模拟器、200 个压缩副本和 38 个其他架构模拟器，并在模拟器中训练策略后放到手工搭建的 MuJoCo 机器人模型中测试。
结论：单步检查会误判设计选择：用模型自身 rollout 训练在 368 步时优于单步训练，但单步领先；剪枝 30% 权重单步保留 90% 技能、2 秒时仅 39%；集成分歧能较好排序 rollout 误差（100 步 Spearman +0.90），但 1σ 覆盖率仅 4.6%，远低于校准估计的 68%；模拟器精度并未预测行走策略成功，18 个微调副本预测更好但 13 个策略失败。
创新点：对已发表学习型模拟器进行严格端到端审计，系统揭示单步评估与长时程/策略级表现之间的错位，并报告了可复现的负面结果与撤回声明。
意义：对世界模型和具身智能中的学习型模拟器评估具有警示意义：不能仅依赖单步预测精度，需要多步滚动和策略级验证。

SpikWM: Efficient End-to-End Spiking World Modeling for Visual Planning

Shuhan Ye, Hongbin Yu, Chong Wang et al.

问题：目标条件视觉规划需要模型能区分不同视觉状态与动作后果，但脉冲神经网络（SNN）的单步脉冲会丢失运动线索、并把产生不同物理结果的动作混在一起，导致世界模型表达能力不足。
方法：提出 SpikWM——一种端到端的脉冲潜空间世界模型，采用 JEPA 式的联合嵌入预测架构，每张图像只做一步仿真、每个潜空间位置只做一次神经更新。具体包括：Spiking Regional Encoding 通过区域池化保留空间线索；Bi-Spike Action Encoding 用正负二值响应联合编码动作；Causal Membrane Prediction 借助可学习的分组时间常数，将阈下证据沿潜空间历史传递。编码器与预测器在无奖励的图像-动作轨迹上联合训练，损失为下一嵌入预测加 SIGReg。
结论：在统一规划器下，Push-T、Two-Room、Reacher、OGBench-Cube 上平均成功率分别达 88.67%、97.33%、99.33%、86.67%，优于两个脉冲基线；消融验证了各模块有效性；在同等规划预算下，估计算术能耗较 LeWM 降低 75.6%。
创新点：将 JEPA 式联合嵌入预测架构与事件式脉冲计算深度结合，用区域池化编码、双极脉冲动作编码和带学习时间常数的因果膜预测，在极低脉冲步数下保留动作与运动信息，实现高效端到端脉冲世界模型。
意义：为低功耗、类脑硬件友好的世界模型与视觉规划提供了可行路径，说明脉冲计算可以在保持规划性能的同时大幅降低能耗，对具身智能与边缘端 Agent 有参考价值。

Residual-Guided Lightweight Reinforcement Learning for Risk-Aware Trajectory Selection with a Frozen World Model

Jiaqi Wu, Yongqi Dong, Yijie Zhong et al.

问题：在自动驾驶中，世界模型会为候选轨迹生成未来场景预测，但固定不变的轨迹选择规则难以体现不同场景下的差异化权衡（如安全与效率）。论文希望在冻结世界模型、固定候选轨迹集的前提下，实现轻量、场景自适应的风险感知轨迹选择。
方法：提出残差引导的强化学习框架：用 PPO 联合微调“候选选择 + 有界轨迹残差”策略，并训练一个上下文条件化的排序网络，从对所选轨迹做局部扰动评估得到的反馈中学习候选偏好。推理阶段用固定权重融合学习到的偏好与预测风险排序，直接返回原候选轨迹而不做修改；残差分支与 critic 仅在训练时使用。
结论：在 nuScenes 验证集开环评测中，相比无 RL 选择的 RiskWorld 基线，平均 L2 轨迹误差降低 3.99%；在反馈访问与 actor 更新预算匹配条件下，残差探索比无残差的分类 PPO 变体再降低 0.83% L2；移除或打乱风险特征时仍保持优于 RiskWorld 的 L2。
创新点：将残差探索限定在训练期、推理期仅保留极轻量（约 1.17 万参数）的场景条件排序网络，在冻结世界模型下实现安全可控的轨迹选择微调。
意义：为世界模型驱动的规划器提供了一种参数开销极小、可直接部署的 RL 适配范式，对具身智能与自动驾驶中的模型复用和安全决策有参考价值。

Reading Scene States: Uncovering Safety Failures in Vision-Language Models

Tongxi Wu, Yuyang Cheng, Jiacheng Xian et al.

问题：视觉语言模型即使在没有显式请求有害目标时，也可能通过理解视觉事件提供有害协助；论文要揭示并系统利用这种“场景状态安全漏洞”。
方法：作者构建 SceneSafetyBench（375 个图像-问题对，覆盖初始/中间/最终场景状态和五种视觉呈现），并提出 S3TA：将有害目标转化为场景状态，独立查询图像-问题对，再组装模型回答以实施攻击。
结论：八个 VLM 在场景状态输入下的攻击成功率为 45.6%–72.3%；S3TA 在 MM-SafetyBench 七类任务、八个开放与商业 VLM 上平均 ASR 达 71.2%，比最强基线高 6.1 个百分点，且文本过滤和视觉审核保护有限。
创新点：首次识别并系统化利用 VLM 通过场景状态推断而产生有害协助的安全漏洞，将隐式场景推理转化为可扩展攻击。
意义：表明 VLM 安全防护不能只筛查输入内容，还需保障模型在场景接地推理过程中推断出的协助行为。

Spool: Low-Latency Streaming Inference for Hybrid Vision-Language Models

Rui Ning, Om Chabra, Hari Balakrishnan

问题：面向视觉无障碍、机器人等需要针对最近一段视频（如近两分钟）快速问答的应用，混合视觉语言模型（注意力+线性循环层，如Gated DeltaNet）维护滑动窗口代价高昂：循环层把历史帧压缩进共享状态，淘汰旧帧通常需重跑整个窗口。
方法：作者发现循环层状态更新对状态是仿射的、系数依赖输入，因此每帧的影响可表示为可结合复合的变换。Spool 是无需训练的框架，缓存逐帧状态变换并在窗口滑动时高效复合，从而在不重跑主干网络的情况下从各循环层状态中精确移除过期帧；同时设计了专用数据结构与 GPU 内核以降低缓存与复合开销。
结论：在 5 个开源混合 VLM 和 4 个视频推理基准的全部 20 项测试中，Spool 均取得最低 p95 首 token 时延，相比两个近期 vLLM 基线中较快者几何平均降低 6.6 倍，同时平均准确率提升 2.3 个百分点。
创新点：利用循环状态更新的仿射可复合性，实现免训练、逐层精确的流式窗口淘汰，避免重放历史帧。
意义：为混合注意力-循环架构的长视频流式推理提供了实用加速方案，对实时多模态 Agent 与具身智能部署有直接价值。

John Gideon, Anshul Gupta, Megan Applegate-Kenton et al.

Learning Grounded Reasoning from Human Gaze

Gabriel Sarch, Declan Campbell, Nicholas Budny et al.

问题：如何有效利用人类注视数据来提升视觉语言模型的视觉推理能力，同时避免注视序列中的噪声和冗余，并保持与人类行为对齐。
方法：作者收集了7,109个人类注视试验，覆盖图表理解、视觉搜索和计数等多样视觉推理任务，并用不同形式的注视引导训练 grounded reasoning 模型；发现将人类注视作为 grounded reasoning 的先验优于直接监督完整注视序列，进而提出 GGR（Gaze-Guided Reasoner），并结合强化学习进一步优化。
结论：GGR 在准确率上匹配或超过领先的 grounded-reasoning 基线，同时具有更好的人类对齐和更可靠的视觉 grounding；强化学习无需注视监督也能提升任务准确率、注视对齐和 grounding 质量，行为分析显示注视监督模型在作答前有更多视觉探索。
创新点：核心创新在于将人类注视用作空间探索先验而非完整行为模仿，并结合强化学习提升视觉推理与人类对齐。
意义：该工作为多模态大模型的 grounded reasoning、人机行为对齐和可解释视觉探索提供了新思路。

WoRD: Diffusion-Based Posterior Inference for Online Goal Recognition

Almog Anschel, Sarah Keren

问题：论文要解决连续轨迹下的在线目标识别问题，尤其是现有符号方法或依赖显式动力学模型的方法在模糊轨迹前缀上难以准确推断智能体目标。
方法：提出 WoRD，利用学习到的轨迹扩散先验从部分观测推断目标；对每个候选目标运行热启动去噪链，通过闭式对数似然梯度将采样引导至观测轨迹，并用贝叶斯规则重加权得到校准的目标后验。

创新点：将扩散模型的后验推断用于在线目标识别，无需显式动力学模型，并通过逐目标去噪、似然引导和贝叶斯重加权实现连续轨迹上的校准多模态推断。
意义：为具身智能与行为理解中的连续目标识别提供了更稳健的概率推断框架，减少对难以获取的动力学模型的依赖。

Vincenzo Marcianò, Xiaoming Zhang, Michela Antonelli et al.

Say Less, Hallucinate Less? Diagnosing and Restoring Object Coverage in Preference-Optimized Vision-Language Models

Hansang Lee

Transfer Once, Ask Locally: Compact Audio-Visual Memory for On-Device Question Answering

Qitong Wang, Jihui Jin, Divya Kothandaraman et al.

问题：这篇论文要解决轻量用户设备上音视频问答的传输与计算成本问题：即使将音视频编码放在服务器、语言解码留在本地，传输和处理完整多模态表示仍然代价很高。
方法：提出一种无需训练、与查询无关的 token 剪枝框架，在传输前构建紧凑且可复用的音视频记忆。将视频时空块和对齐音频窗口视为 player，用蒙特卡洛 Shapley 估值衡量重要性，并结合查询无关效用、跨模态冗余校准和单模态多样性边际覆盖增益的嵌入覆盖目标，在有限 token 预算下保留高分 player 的原始 token 嵌入，一次传输后供本地后续问题复用。

创新点：核心创新是用 Shapley 估值与嵌入覆盖目标构建无需训练、与查询无关且可一次传输多次复用的紧凑音视频记忆。
意义：该工作对隐私保护、低延迟、低通信成本的端侧多模态问答具有实际意义，也为可复用多模态记忆压缩提供了新思路。

PhysScope: Agentic Multimodal Physics Reasoning with Grounded Visual Memory

Haoyang Liu, Kecheng Liang, Xinyu Li et al.

问题：视觉语言模型虽能读懂物理图示，却常把物理约束用在不适用的状态或条件下，导致前提性错误沿多步计算传播；论文要解决这类“作用域错配”问题。
方法：提出 PhysScope——一个推理时的视觉外挂框架，不更新模型权重，而是把物理作用域直接绑定到视觉观察上，并显式构造派生视图辅助推理。框架对状态区分、适用条件和物理作用域施加显式约束，并对 agent 提出的修订对照来源与作用域进行校验；被接受的修订会使已登记的依赖项失效，从而维护作用域感知的工作记忆。
结论：在 PhysAlign 上，六个评测 VLM 的求解得分均高于直接求解；以 Gemini-3.8-flash 为例，比 Canvas-CoT 高出 9.34 个百分点，并在分布外基准 PhysUniBench 上显著提升求解准确率。消融实验支持“显式作用域管理 + 依赖维护”作为多模态物理推理 agent 的设计原则。
创新点：把物理前提与适用范围显式建模为可校验的“作用域”，并用依赖失效机制实现无需训练的自我纠错。
意义：为多模态推理与 Agent 提供了可插拔的作用域感知记忆与自纠错范式，对科学推理的可信性有直接价值。
