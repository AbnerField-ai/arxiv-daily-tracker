EvoWorld: Towards Out-of-Sight World Evolution in Generative Video Models

Yequan Bie, Dengyang Jiang, Zhixuan Chen et al.

问题：现有扩散式视频生成模型只擅长渲染逼真的像素，缺乏显式的世界状态维护与因果推理机制，当事件发生时无法推断其后果（如野兽出现后人该逃跑还是反击），常生成视觉合理但行为静态或因果不一致的视频。论文将这一问题形式化为“视野外因果演化”（Out-of-Sight Causal Evolution）任务。
方法：提出 EvoWorld 框架，采用“大脑-渲染器”协作架构：以视觉语言模型作为世界大脑，观察已生成的视频片段、维护不断更新的世界状态描述，并推理事件导致的合理状态转移；再由片段自回归的视频渲染器将这些状态在视觉上实现。同时构建 EvoWorld-Data 训练数据与 EvoWorld-Bench 评测基准，覆盖事件呈现、因果反应与重访一致性三类指标。
结论：实验表明 EvoWorld 在保持视觉质量与时空一致性的同时，显著优于近期模型的事件条件因果演化能力，为超越当前视野的推理引导式自主世界演化提供了参考基线。
创新点：首次提出并形式化“视野外因果演化”问题，并用 VLM 世界大脑 + 自回归视频渲染器的解耦协作架构把世界状态推理与像素渲染分离。
意义：为生成式视频模型从“像素模拟器”迈向具备因果推理能力的世界模型提供了新任务定义、数据与评测基准，对世界模型与具身智能的想象推演具有推动作用。

Motion-guided Contrastive Regularization For Latent World Models

Yiwen Chen, Qiqi Hou, Jisoo Jeong et al.

问题：JEPA 类潜世界模型仅靠分布正则化，无法保证编码保留控制所需信息，会出现静态坍缩：编码器保留每回合特有的静态背景内容，却抑制与操作相关的状态变化，导致在随机背景下规划性能大幅下降。
方法：提出运动引导的对比正则化：将预测的潜在状态转移与同一回合内候选观测的状态转移进行对比，用光流相似度作为软对比目标，使运动相似的候选获得相似的监督；再与潜在预测和 SIGReg 结合，鼓励表示保留回合内的状态区分度以及相关转移之间的相似性。
结论：在 OGBench-Cube 随机背景下，规划成功率从 LeWM 的 52% 提升到 78%；在 LIBERO-Object 上从 14% 提升到 54%；同时在另外四个视觉控制基准上保持相当性能。
创新点：首次识别并系统分析了潜世界模型中的静态坍缩问题，并用光流引导的软对比正则化，把运动信息注入 JEPA 式世界模型的表示学习。
意义：为 JEPA 类世界模型提供了不依赖重建、能增强控制相关表示的正则化手段，有助于提升具身智能和视觉控制任务在视觉干扰下的鲁棒性。

Rui Zhu, Xurui Li, Haixu Tang

方法：将学习到的状态-动作-效果关系作为离线契约，用干净留出转移校准报警阈值；比较岭回归前向残差、四分量联合高斯混合模型及其精确条件密度，并用固定逆词表进行闭集定位。

Visual Token Routing: Learning to keep tokens that matter

Pranjal Aggarwal, Sean Welleck

问题：计算机使用智能体（CUA）需要处理大量截图视觉 token，导致上下文过长和计算成本过高，限制了其在长程任务和实时场景（如视频游戏）中的应用。
方法：论文提出 Visual Token Routing（VTR），联合训练视觉语言模型与轻量级时空路由器；路由器检查当前及前一截图中的每个图像区域，决定其视觉 token 是否进入语言模型，并用自适应损失在尽量少用 token 与保持性能之间权衡。
结论：仅训练 2000 步，VTR 在 OSWorld、CUA-World 和视频游戏动作预测上匹配全分辨率模型性能，同时减少 2.5-5.8 倍视觉 token，推理成本最多降低 3.3 倍、prefill 最多加速 2.9 倍；在 OSWorld 上比降低分辨率和其他丢 token 基线最高高 12.8 分。
创新点：核心创新是面向计算机使用智能体的时空视觉 token 路由机制，通过联合训练学习稀疏视觉表示，只保留对下一步动作有用的视觉信息。
意义：该方法显著降低多模态智能体的视觉 token 计算成本，有助于推动长程任务和实时交互场景中的计算机使用智能体落地。

From Pixels to Actions - Towards Native Vision-Language-Action Policies

Weichen Fan, Haiwen Diao, Penghao Wu et al.

问题：现有视觉-语言-动作模型（VLA）普遍先用固定视觉编码器把感知压缩成单一视觉表示，再开始动作推理，这会丢失对操作至关重要的局部几何、边界、深度和细微状态变化等信号。论文追问：动作策略应继承固定的视觉终点，还是应直接访问不断演化的视觉计算？
方法：提出 NEO-VLA，一种结构上无编码器（encoder-free）的 VLA 框架：图像经轻量 patch 卷积层直接 token 化，并与语言 token 在主干网络中联合演化；一个 flow-matching 动作专家可从不同深度的、受指令条件化的视觉表示中提取信息来生成动作。
结论：在受控对比下，原生（无编码器）架构一致优于基于编码器的对应方案；全量微调只能缩小而不能消除差距，单纯扩大规模也无法弥补。逐层探针显示，动作关键信号常在最终视觉表示之前就已达到峰值。在多种操作场景与分布偏移下，NEO-VLA 取得更强、更鲁棒的控制性能。
创新点：打破“先编码再推理”的固定视觉瓶颈，让动作策略直接读取主干中多层、动态演化的视觉计算，并用逐层探针实证动作关键信息并不在最后一层。
意义：为具身智能与 VLA 模型的结构设计提供了新范式：视觉表示不应是固定端点，而应是可供下游动作按需取用的层级计算资源，对多模态大模型与机器人策略架构均有启示。

方法：论文提出 DreamRealm 后训练框架：先用 RealmForgePipe 从目标模型中挖掘已观察和潜在幻觉，并通过最小图像编辑将幻觉“实体化”，构建 RealmSet 数据集；再用 RealmMatch 在图像-回答组合上构建似然得分矩阵，结合监督学习和双向对比损失，强化正确匹配并抑制错误匹配。
结论：相比原始 Qwen3.5-9B，DreamRealm 在六个视觉感知与幻觉基准上均有提升，其中 HallusionBench 准确率提升 7.26 个百分点，MMVP pair 准确率提升 11.34 个百分点。消融实验也验证了数据构建和训练方法的有效性。
创新点：核心创新是把目标模型自身的幻觉响应通过最小图像编辑变成“可支持的图像”，并将幻觉抑制转化为图像-响应匹配任务，配合双向对比学习进行监督。
意义：该工作为提升多模态大模型视觉感知可靠性和缓解幻觉提供了新的后训练范式，强调围绕模型自身感知混淆构造监督信号。

方法：论文构建了 AmbiHTMLBench 基准，包含 1,115 个多样化真实页面和结构化标注；要求模型根据输入文档恢复可执行 HTML，并采用两套协议评估：客观协议对齐真值与预测的渲染块，衡量表格保真度、页面级文字错误和二维布局一致性；参考锚定协议则通过使 LLM 评判与人类偏好对齐来衡量感知保真度。此外，论文还微调了一个小参数专家模型进行领域适配。

创新点：论文以可执行 HTML 作为文档解析的输出与评测对象，并设计了客观渲染对齐与人类偏好锚定相结合的双协议评测基准。
意义：为多模态文档理解与解析系统提供了更具诊断性的测试平台，推动输出表示从 Markdown 走向保留布局与视觉语义的可编辑 HTML。
