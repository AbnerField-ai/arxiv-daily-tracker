RSI-Anything: Unlocking Recursive Self-Improvement with World Models

Taoyong Cui, Pinxian Zeng, Wanghan Xu et al.

问题：递归自我改进（RSI）希望将交互经验转化为持续能力提升，但外部反馈成本高，且随着策略演化，世界模型预测可能变得不可靠。
方法：提出领域通用的 RSI-Anything 框架，基于 JEPA-Anything，用预测式世界模型指导动作与学习数据选择；观测反馈驱动策略/工作流改进和条件式世界模型适配，并通过组件与兼容性检查决定是否保留更新后的策略-模型对。
结论：在多个计算与科学领域取得显著增益：代码修复成功率从 26.3% 提升到 31.2%，GUI 任务完成率更高且平均动作数减少 39.4%，实验室规划分数从 21.80% 提升到 46.01%，反应优化在相同预算下达到 96.15% 平均最佳产率，优于贝叶斯优化的 82.16%。
创新点：将预测式世界模型、策略/工作流更新与更新保留检查结合，形成一个可跨领域实现递归自我改进的通用框架。
意义：表明世界模型与可保留的系统更新能降低反馈依赖，并在多样环境中实现持续自我改进，对世界模型、Agent 和自主进化系统研究有推动作用。

SimVTA: Simulation-Grounded Video-Trajectory Alignment for Driving World Action Models

Changhui Jing, Haochen Tian, Hongchen Li et al.

问题：驾驶世界动作模型（WAM）通过强化学习后训练可以探索替代轨迹，但驾驶日志只包含实际记录轨迹的未来视频，导致这些替代轨迹缺乏对应的视觉监督。
方法：SimVTA 是一个基于仿真的后训练框架：先为每个观测采样候选轨迹，并用真实世界模拟器（如 World Engine）在 3DGS 重建场景中为高奖励候选渲染未来视频；在有限渲染预算下优先监督高误差未来，再结合 GRPO 优化轨迹规划，并用匹配视频上的 flow-matching 损失更新共享表征。
结论：在 NAVSIM v1 上，将 SimVTA 应用于 WAM 初始化可将 PDMS 从 86.2 提升到 91.3（+5.1）；在 NAVSIM v2 上达到 88.2 EPDMS，在 HUGSIM 闭环评估中平均 HD-Score 为 38.8。消融实验表明，用视频监督更新共享表征可提升规划，优先监督高奖励轨迹中的高误差未来还能进一步提升性能。
创新点：将仿真渲染的轨迹匹配视频监督与强化学习轨迹优化结合，为驾驶 WAM 的替代轨迹提供独立于模型自身预测的视觉监督，并更新共享表征。
意义：为驾驶世界动作模型的可扩展后训练提供了新思路，使反事实轨迹也能获得视觉监督，从而同时提升规划性能与世界模型表征。

Noise Space Learning for VLA Adaptation

Junjie Lu, Chuheng Zhang, Yucen Wang et al.

问题：预训练VLA模型虽然具备通用操作先验，但在特定任务适配时需在有限机器人交互、计算资源和安全约束之间取得平衡。
方法：提出噪声空间学习（NSL），在固定预训练流匹配VLA的前提下，学习一个上下文条件化的噪声分布，并将PPO、SAC、AWR等强化学习算法统一用于该适配接口。
结论：在LIBERO、RoboTwin及四个真实机器人操作任务中验证了多种NSL变体的有效性，并给出了不同资源与部署条件下的选择建议。
创新点：将流匹配VLA的噪声空间作为适配接口，兼容多种学习算法，并从信息论角度分析其高效适配机制。
意义：为VLA模型在真实机器人任务中的低成本、安全、高效适配提供了新范式和实践指导。

Images Talk Back: Guiding MMDiTs by Suppressing Image-to-Text Feedback

Yucheng Yang, Xiaoxiao Sun, Shusheng Yang et al.

问题：多模态扩散Transformer（MMDiT）中，演化图像会通过联合注意力更新文本表示，进而影响后续图像生成；论文要探究这种图像到文本（I2T）反馈到底有助于纠正提示偏差，还是会保留已有错误。
方法：作者通过干预实验发现I2T反馈会保留图像中已存在的物体和属性（包括错误），并提出语义反馈引导（SFG）：通过远离一个强化I2T反馈并弱化文到图条件的辅助分支来抑制I2T反馈；原地版本iSFG直接抑制I2T并增强文到图条件，无需额外模型评估。SFG分支仅在图像采样前20%步骤运行。
结论：在三个图像生成骨干上，SFG/iSFG提升了提示对齐和偏好模型分数：FLUX上CFG+SFG将GenEval从0.6661提升到0.7479；SD3.5M上iSFG在零额外NFE下比CFG提升+1.33 HPSv2.1；方法还可迁移到文生视频和图生视频，提升VBench分数。
创新点：揭示了MMDiT中I2T反馈会固化图像中的错误，并提出无需额外评估或极少额外计算即可抑制该反馈的引导方法。
意义：为多模态扩散模型的理解与可控生成提供了新机制洞察和实用改进，并可推广到视频生成任务。

LapMerge: Differentiable Exact-Budget Token Merging in Linear Time

Magdalena Trędowicz, Aleksandra Nowak, Tomasz Steifer et al.

问题：现代视觉和语言模型处理的长 token 序列成本很高，而现有 token 压缩方法在丢弃信息与依赖高代价成对匹配/全交互合并之间难以兼顾。
方法：提出 LapMerge，一种面向有序序列的可微 token 合并算子：用学习到的质量分布和 Laplace 核密度将序列划分为恰好 N 个等质量段，再通过前缀/后缀扫描聚合各段，使前向与反向均为 O(M+N)。
结论：在视觉和视觉语言任务中，LapMerge 匹配或优于强 token 压缩器，并在长序列上最高快两个数量级；当 token 顺序体现场景或时间局部性时尤其有效。
创新点：首次在有序序列 token 合并中同时实现精确输出预算、端到端可微和线性时间复杂度。
意义：为长序列视觉/语言模型提供高效、可微且可控预算的 token 压缩模块，有助于降低下游计算成本并融入模型架构设计。

Yuhong Liu, Shenxi Wu, Junyi Chi et al.

问题：当前大型视觉语言模型（LVLMs）缺乏主动空间心理化（ASM）能力，即无法像人类一样主动从任务相关视角重新观察场景并重构空间布局，导致复杂空间推理能力不足。

Hide and Seek: HIDE Concepts to SEEK explanations for black box models

Bhanu Tokas, Rahul Nair, Rockwell Jackson et al.

问题：现有基于概念的归因方法通常只能解释分类和回归模型，且需要模型权重或大量概念标注数据，多数无法提供图像级归因。本文旨在为黑盒视觉模型提供无需权重和概念标注数据集的概念级归因。
方法：提出 Hide and Seek（HnS）：给定概念和图像集，先用视觉语言模型检索与概念对齐的图像，并在每张图像中定位该概念；随后遮蔽定位区域，通过比较原始图像与遮蔽图像在黑盒模型输出上的变化来度量归因。该方法直接测量模型行为，支持局部归因，且无需访问模型权重或标注概念数据集。
结论：在 CelebA 和 COCO-Stuff 上，HnS 与真实归因的一致性优于现有方法；并成功应用于图像描述和卫星图像分割等任务，而这些任务此前没有可用的概念归因方法。
创新点：首次实现无需模型权重和概念标注数据的黑盒视觉模型概念级局部归因，借助视觉语言模型完成概念检索、定位与遮蔽来测量模型输出变化。
意义：扩展了概念归因方法的适用范围，使黑盒视觉模型在更广泛任务上可解释，有助于提升AI的可信性与可解释性。

SeoulMMOD: A Large-Scale Multimodal Origin-Destination Flow Benchmark

Taeyoung Yu, Seonbin Jo, Jiwon Kim et al.

问题：现有城市OD流预测基准通常只覆盖单一或至多两种交通方式，难以区分出行方式转移与总出行需求变化，尤其缺乏全市多模式、多年份的公开数据。

创新点：提出了覆盖全市、多交通方式、多年份且含丰富外部信号的大规模多模态OD流公开基准。
意义：为城市时空预测、多模态出行建模和可复现基准评测提供了重要测试平台。

AudioTETRIS: Token Elimination via Transitional Importance Signals for Efficient Audio LLMs

Shreya Sajid, Anna Vettoruzzo, Joaquin Vanschoren

问题：大型音频语言模型（LALM）的音频编码器即使对短音频也会产生数百个 token，自注意力随序列长度平方增长导致推理算力开销巨大；而现有免训练压缩方法仅依据粗粒度注意力或特征相似度剪枝/合并 token，把音频 token 当作各向同性的通用特征，抹平了频谱过渡，破坏了语音解码所依赖的细粒度音素过渡信息。
方法：提出 AudioTETRIS，一个免训练的两阶段框架：先利用音频编码器的表示几何（representation geometry）作为声学先验来刻画 token 重要性，再将这一先验从编码阶段传递到 LLM 解码器，计算逐 token 的融合分数；该分数驱动解码器各层进行渐进式 top-k token 选择，无需额外训练或辅助模型。
结论：在 Qwen2-Audio-7B、Phi-4-Multimodal 和 Audio Flamingo 3 上评测，仅保留 25% 音频 token 即可在多项语音任务上接近未压缩性能，在中等压缩率下匹配甚至超越全 token 准确率，并持续优于现有免训练基线。
创新点：首次把音频编码器的表示几何结构作为声学先验直接传播到 LLM 解码器，以融合重要性分数驱动渐进式 token 选择，实现面向语音过渡结构的高效免训练压缩。
意义：为音频/多模态大模型的推理效率提供了无需训练、即插即用的 token 压缩思路，凸显了将模态自身的结构化先验引入解码过程的价值，可推广到其他长序列多模态场景。

Can Multimodal Decision Models Classify Breast Ultrasound Images? Benchmarking CLEF and CLEF-Flash Across Prompts and Datasets

Tran Cao Minh, Hai Tran, Ha Minh Tan

问题：评估多模态决策模型 CLEF 和 CLEF-Flash 能否用于乳腺超声图像分类，并考察提示词和数据集差异对性能的影响。
方法：在 Dataset B、BUSI 和 BUS-BRA 共 2818 张乳腺超声图像上，保持模型参数不变且不做用户自定义预处理，使用三种提示词（最小标签、明确分类任务、超声临床标准）进行推理，并报告准确率、宏 F1、平衡准确率、吞吐量和延迟等指标。

创新点：系统基准测试了 CLEF/CLEF-Flash 在乳腺超声分类中对提示词和数据集差异的敏感性。
意义：表明多模态决策模型用于医学图像分析前需进行数据集和提示词相关的类别特异性评估。

AudioTETRIS: Token Elimination via Transitional Importance Signals for Efficient Audio LLMs

Shreya Sajid, Anna Vettoruzzo, Joaquin Vanschoren

问题：大型音频语言模型（LALM）的音频编码器即使对短音频也会产生数百个 token，自注意力随序列长度平方增长导致推理算力开销巨大；而现有免训练压缩方法仅依据粗粒度注意力或特征相似度剪枝/合并 token，把音频 token 当作各向同性的通用特征，抹平了频谱过渡，破坏了语音解码所依赖的细粒度音素过渡信息。
方法：提出 AudioTETRIS，一个免训练的两阶段框架：先利用音频编码器的表示几何（representation geometry）作为声学先验来刻画 token 重要性，再将这一先验从编码阶段传递到 LLM 解码器，计算逐 token 的融合分数；该分数驱动解码器各层进行渐进式 top-k token 选择，无需额外训练或辅助模型。
结论：在 Qwen2-Audio-7B、Phi-4-Multimodal 和 Audio Flamingo 3 上评测，仅保留 25% 音频 token 即可在多项语音任务上接近未压缩性能，在中等压缩率下匹配甚至超越全 token 准确率，并持续优于现有免训练基线。
创新点：首次把音频编码器的表示几何结构作为声学先验直接传播到 LLM 解码器，以融合重要性分数驱动渐进式 token 选择，实现面向语音过渡结构的高效免训练压缩。
意义：为音频/多模态大模型的推理效率提供了无需训练、即插即用的 token 压缩思路，凸显了将模态自身的结构化先验引入解码过程的价值，可推广到其他长序列多模态场景。
